# A2 上 PanGu 1B 与 Qwen 1.7B 的 OneRec 下游精度对比

2026-11-27 整理。将线性层切换为 MXFP8 模拟后，四个推荐任务的 SID Pass@32 等权平均下降了 0.003976（PanGu 1B）和 0.006008（Qwen 1.7B）。分类任务 Label-Pred 的 AUC 分别下降 0.003699 和 0.023334。

## 评测口径

- **模型与运行方式**　PanGu 1B SFT step5000 与 OneRec Qwen 1.7B 分别使用自己的 BF16 基线。在 A2 上通过 vLLM-GR eager 推理，低精度组在线性层对权重和激活使用 AscendC 融合 DQD 模拟 MXFP8（E4M3FN，块大小 32，`scale_alg=1`），随后执行 BF16 矩阵乘。
- **数据与评分**　每轮使用相同的五个 OneRec 全量测试集，共 475,449 条。沿用训练侧评测口径，输入不额外截断、不打包。四个推荐任务使用 Beam32，按 SID 统计 Pass@1、Pass@32、Recall@32。Label-Pred 用“是／否”的首 token 概率计算 AUC。
- **读表方式**　Δ = MXFP8 − BF16，负数表示下降，正数表示提升。分数和差值均以原始小数表示，各自保留六位。
